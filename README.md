# أبيات الحجاز — كتالوج مواد البناء
**Abiat Al-Hijaz — Building Materials Catalog**

موقع كتالوج احترافي ثنائي اللغة (عربي / إنجليزي) لمتجر أبيات الحجاز لمواد البناء في جدة.

A professional bilingual (Arabic / English) product catalog for Abiat Al-Hijaz building materials store in Jeddah, Saudi Arabia.

---

## 🚀 التشغيل المحلي / Local Development

```bash
npm install
npm run dev
```

الموقع سيعمل على: http://localhost:5173

---

## 🏗️ البناء / Build

```bash
npm run build
```

الملفات ستُصدَّر في مجلد `dist/`

---

## ☁️ النشر على Vercel / Deploy to Vercel

1. ارفع المشروع على GitHub
2. اذهب إلى [vercel.com](https://vercel.com) وسجّل دخول
3. اضغط **Add New → Project**
4. اختر المستودع من GitHub
5. إعدادات Vercel تلقائية:
   - **Framework**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
6. اضغط **Deploy** ✅

---

## 🛠️ التقنيات / Tech Stack

- **React 18** + TypeScript
- **Vite** (build tool)
- **Tailwind CSS v4**
- **Lucide React** (icons)
- **React Icons** (Instagram icon)
- **Wouter** (routing)
